# daily-cpp

每天一个可编译的 C++ 小程序，从零开始系统练习 C++。

## 目录结构

```
daily-cpp/
├── day001_hello/       # Day 1: Hello World
│   └── main.cpp
├── day002_xxx/         # Day 2: ...
└── ...
```

## 编译方法

```bash
cd day001_hello
g++ -std=c++17 -o main main.cpp
./main
```
